# 🎤 Kpop Agency Simulator


A management simulation game inspired by Idol Manager, focused on the K-pop industry.  
Build your own entertainment company, recruit trainees, and create the next generation of idols.

---

## 🚧 Status

This project is currently in active development.


---

## 🎮 About the Game

Kpop Agency Simulator is a management simulation game where the player takes on the role of a CEO of a K-pop entertainment agency.

You will:
- Recruit trainees through auditions
- Manage and train idols
- Build your own groups
- Make strategic decisions to grow your company
